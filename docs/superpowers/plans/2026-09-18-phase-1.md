# Jev CLI Phase 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a Python CLI `jev` that evaluates TypeSafe System One questions and prints a JSON envelope.

**Architecture:** Thin typer commands call `TypeSafeClient`. Question files are validated locally before any HTTP. Stdout is `{status, data, metadata}`; errors go to stderr as JSON.

**Tech Stack:** Python 3.10+, `typesafe-sdk`, `typer`, `pytest`

## Global Constraints

- Binary name is `jev`. Import package is `jev_cli`. Env vars are `TYPESAFE_*`.
- Language is Python, not Rust, not Java/JVM.
- HTTP only through `typesafe_sdk.TypeSafeClient`. No urllib, no adapter.
- Phase 1 only: `auth status`, `models`, `ask`, `noul`, `choice`, `score`, `smoke`.
- Do not add `agent schema`, `skills install`, `--backend llm`, or `--min-confidence`.
- JSON envelope is the only output format in Phase 1.
- Exit 0 answered, 1 request failed, 2 bad usage/questions.
- Tests must not require a live `TYPESAFE_API_KEY`. Mock the client.

**Files:**

**Interfaces:**
- Consumes: JSON path or dict
- Produces:

```python
class QuestionError(ValueError): ...

def load_questions(data: dict) -> dict: ...
# returns a mapping of id -> {"type", "instructions", "criteria"?}
# accepts either {"questions": {id: {...}}} or a top-level map of id -> question
# also accepts {"questions": [ { "id", "type", ... } ]}

def load_state(raw: str | dict | list) -> str | dict | list: ...
```

Rules (exit 2 before HTTP):
- every question needs `type` in `{noul, choice, score}` and non-empty `instructions`
- choice `criteria` must be a map with at least two keys
- score `criteria` must be a list with at least two levels
- duplicate ids fail
- empty questions fail

**Interfaces:**

```python
def answers_to_dict(response) -> dict: ...
# { "model", "answers": { id: {type, noul|choice|score, ...} }, "usage": {input_tokens, output_tokens} }

def system_one(*, config: Config, state, questions: dict, model: str | None = None): ...
```

Serialize answers:

- noul: `{"type": "noul", "noul": float}`
- choice: `{"type": "choice", "choice": str, "probabilities": dict, "confidence": float}`
- score: `{"type": "score", "score": float, "legend": dict, "probabilities": dict, "confidence": float}`

Score `legend`/`probabilities` keys may be ints from the SDK; stringify them in JSON.

**Interfaces:**

```python
@app.command("ask")
def ask(
    state: str | None = typer.Option(None, "--state"),
    state_file: Path | None = typer.Option(None, "--state-file"),
    questions_file: Path | None = typer.Option(None, "--questions-file"),
    model: str | None = typer.Option(None, "--model"),
    key: str | None = typer.Option(None, "--key"),
    creds: Path | None = typer.Option(None, "--creds"),
) -> None: ...
```

State: `--state` string, or `--state-file` JSON/text (`-` = stdin). Questions: required `--questions-file`. Missing questions or invalid questions → exit 2. Missing API key → exit 1 with error envelope. On success print success envelope to stdout.

- [ ] **Step 1: Write CLI tests with a monkeypatched `system_one`**

```python
def test_ask_prints_envelope(tmp_path, monkeypatch):
    q = tmp_path / "q.json"
    q.write_text('{"urgency": {"type": "noul", "instructions": "urgent?"}}')
    s = tmp_path / "s.json"
    s.write_text('"help now"')
    monkeypatch.setenv("TYPESAFE_API_KEY", "k")
    monkeypatch.setattr(
        "jev_cli.commands.ask.system_one",
        lambda **kwargs: {
            "model": "jev-1.13.0",
            "answers": {"urgency": {"type": "noul", "noul": 0.9}},
            "usage": {"input_tokens": 1, "output_tokens": 1},
```
